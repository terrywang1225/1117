# Terry Wang — Personal Portfolio

A responsive, single-page personal portfolio built with Bootstrap 5, custom CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser, or serve the folder using `python3 -m http.server 8000` and visit http://localhost:8000.

## Publish
Upload **all files and folders** inside `terry-portfolio` to your website's public root (often `public_html`), or deploy the folder to Netlify / GitHub Pages. The home page must remain named `index.html`.

Bootstrap 5 and Google Fonts load from public CDNs, so internet access is required for those resources. The photos, CSS, JS and CV are included locally.

## Customize
- `index.html`: text, project details, links and sections
- `css/style.css`: colors, typography, spacing and layout
- `js/main.js`: mobile navigation behavior
- `assets/`: your photos and PDF resume

## Notes
- Current project descriptions and metrics are based on the provided CV.
- The typographic project covers are newly created placeholders, not original campaign graphics.
- Check image permissions and company confidentiality before public publishing.
- Verify your public contact information before deploying.
